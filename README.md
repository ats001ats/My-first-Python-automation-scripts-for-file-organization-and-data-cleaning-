# Python Automation & Utility Scripts Hub

This repository contains my collection of professional Python automation and utility scripts designed to solve everyday tasks efficiently.

## 🚀 Projects Included:
1. **File Organizer**: Automatically sorts messy files into categorized folders.
2. **CSV Data Cleaner**: Cleans extra spaces, fixes formatting, and removes duplicates from data files.
3. **Secure Password Generator & Checker**: Generates strong custom passwords and analyzes their security strength.
4. **Advanced To-Do List Manager**: CLI-based task manager with JSON file saving, priority settings, and status tracking.
5. **Pro Web Scraper**: Extracts structured data (quotes/articles) from multi-page websites and exports it directly to CSV.
6. **Portfolio Hub (`portfolio_hub.py`)**: An interactive dashboard to run and control all these projects from a single menu.
